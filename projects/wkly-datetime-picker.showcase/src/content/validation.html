Validate selections with Angular forms

required rejects an empty selection. min and max are inclusive canonical values in the selected mode's format. Disabled-date callbacks receive an epoch day and calendar context; disabled-time callbacks receive seconds since midnight. These constraints apply to calendar selection, manual entry, Now, and validation of values supplied by the application.

Angular reactive forms example

Import both modules and let the form control own the value. This booking window excludes Sundays and the noon hour. Call appointment.setValue(null) to clear it and appointment.disable() to disable the picker through the form. 

import { Component } from '@angular/core';
import { FormControl, ReactiveFormsModule } from '@angular/forms';
import {
  WklyDateTimePickerModule, WklyPickerValue,
  WklyDisabledDatePredicate, WklyDisabledTimePredicate,
} from '@wkly/datetime-picker';

@Component({
  selector: 'app-validated-booking',
  standalone: true,
  imports: [ReactiveFormsModule, WklyDateTimePickerModule],
  template: `
    <wkly-datetime-picker
      mode="datetime" [formControl]="appointment" [required]="true"
      min="2099-12-01T00:00:00.000Z"
      max="2100-01-31T23:59:00.000Z"
      [isDateDisabled]="sunday" [isTimeDisabled]="noon">
    </wkly-datetime-picker>
    <p role="status">Form status: {{ appointment.status }}</p>
  `,
})
export class ValidatedBookingComponent {
  appointment = new FormControl<WklyPickerValue>(null);
  sunday: WklyDisabledDatePredicate = (day) =>
    new Date(day * 86400000).getUTCDay() === 0;
  noon: WklyDisabledTimePredicate = (seconds) =>
    seconds >= 12 * 3600 && seconds < 13 * 3600;
}

Draft errors and committed values

The picker implements Angular's value accessor and validator contracts. A manual February 31 stays visible as an invalid draft; it does not silently become a March date or replace the last committed value. The form can therefore be invalid while its control still holds the previous selection. validationChange reports structured errors, including endpoint and field information where available. Typed times also obey minute and second steps.

Ranges check both endpoints and, by default, disabled values between them. allowRangeAcrossDisabled relaxes only the crossing rule. rangeValidator can add a whole-range constraint; use validators for other selection rules. Programmatic writes are validated without calling the registered user-change callback. Keep save actions tied to the form's validity as well as its current value.

See range editing behavior and the validation types and error codes. The generic FormControl example uses Angular's typed forms available from Angular 14; on earlier versions use an untyped control.
