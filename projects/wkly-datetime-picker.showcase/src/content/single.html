Configure date and time selection

Choose mode="date" for a day without a time, time for a clock time without a selected day, or datetime for both. A date emits a string such as 2099-12-16T00:00:00.000Z. Time mode uses the fixed date 0000-01-01, for example 0000-01-01T13:00:00.000Z. An empty selection is null.

Angular example: appointment time

This standalone component uses five-minute increments. Import WklyDateTimePickerModule in the host component or NgModule; [(value)] receives successful commits through valueChange. Inline edits commit when a valid action completes. 

import { Component } from '@angular/core';
import { WklyDateTimePickerModule, WklyPickerValue } from '@wkly/datetime-picker';

@Component({
  selector: 'app-appointment',
  standalone: true,
  imports: [WklyDateTimePickerModule],
  template: `
    <wkly-datetime-picker
      mode="datetime"
      [(value)]="appointment"
      hourCycle="h24"
      [minuteStep]="5"
      ariaLabel="Appointment date and time">
    </wkly-datetime-picker>
  `,
})
export class AppointmentComponent {
  appointment: WklyPickerValue = '2099-12-16T13:00:00.000Z';
}

Manual entry and time display

Manual fields use the same constraints as calendar selection. An impossible date or a minute outside the configured step remains editable and does not replace the committed value. Both minuteStep and secondStep must be positive integer divisors of 60. Set [showSeconds]="true" to edit seconds; otherwise they must be 00. Milliseconds are always .000.

hourCycle accepts locale, h12, h24, or switchable. AM/PM changes the time presentation, but not the underlying value. Values remain canonical Gregorian UTC strings. The demonstrations' “Show local time” option shifts only the Now action's wall-clock fields and still emits a Z suffix; it does not convert existing selections. Your application owns timezone interpretation and conversion.
