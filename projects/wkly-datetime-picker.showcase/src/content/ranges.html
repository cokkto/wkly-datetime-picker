Configure and edit a range

date-range stores two midnight UTC dates; time-range stores two clock times on 0000-01-01; datetime-range keeps a date and time at each endpoint. A completed selection is an ordered readonly pair of canonical ISO strings. An empty selection is null, and an incomplete calendar selection stays in the draft. Equal endpoints are allowed.

Angular example: booking window

Use WklyPickerValue for a two-way binding because the output can also be null. Here the initial pair supplies independent start and end times, with inclusive bounds for both endpoints. 

import { Component } from '@angular/core';
import { WklyDateTimePickerModule, WklyPickerValue } from '@wkly/datetime-picker';

@Component({
  selector: 'app-booking-window',
  standalone: true,
  imports: [WklyDateTimePickerModule],
  template: `
    <wkly-datetime-picker
      mode="datetime-range"
      [(value)]="booking"
      [minuteStep]="15"
      min="2099-12-01T00:00:00.000Z"
      max="2099-12-31T23:45:00.000Z">
    </wkly-datetime-picker>
  `,
})
export class BookingWindowComponent {
  booking: WklyPickerValue = [
    '2099-12-16T09:00:00.000Z',
    '2099-12-17T17:00:00.000Z',
  ];
}

Endpoint ordering and validation

Selecting the end date before the start date swaps the endpoints. Manual edits use the same ordering when the field edit completes. For date and date-time ranges, the Manual section also offers “In X days” mode: a signed calendar-day difference from Start date, for user's convenience. Typing a negative number previews the earlier end until Enter, blur, or the one-second typing delay completes the edit. Entering manual mode fills missing date-range endpoints; valid defaults can commit immediately inline.

Disabled endpoints always fail validation. By default a range also cannot cross disabled dates or times. [allowRangeAcrossDisabled]="true" permits crossing them but keeps endpoint checks. Use rangeValidator for rules on a complete ordered pair. A time range is ordered within one fixed day; use a date-time range for an interval that crosses midnight. Invalid drafts keep the previous committed start-end pair.

Try the validation and forms examples, and see the selection constraint reference for callback inputs.
