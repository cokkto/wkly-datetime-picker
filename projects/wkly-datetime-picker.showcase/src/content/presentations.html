Present the picker in an Angular application

An inline picker stays in the page and commits valid completed actions immediately. A native dialog gives the task a modal surface without an additional UI package. An input-anchored overlay fits a form where the picker should appear only when needed. Both transient presentations edit a draft: Confirm commits it; Close, Escape, or backdrop dismissal discards it.

Angular example: inline, dialog, and CDK overlay

The base module provides the component and native dialog directive. For the overlay, install @angular/cdk with the same major as Angular, import the optional module below, and include @angular/cdk/overlay-prebuilt.css in your global stylesheet. Inline and native dialog usage do not require CDK. 

import { Component } from '@angular/core';
import { WklyDateTimePickerModule, WklyPickerValue } from '@wkly/datetime-picker';
import { WklyDateTimePickerOverlayModule } from '@wkly/datetime-picker/cdk-overlay';

@Component({
  selector: 'app-picker-presentations',
  standalone: true,
  imports: [WklyDateTimePickerModule, WklyDateTimePickerOverlayModule],
  template: `
    <wkly-datetime-picker mode="datetime" [(value)]="value">
    </wkly-datetime-picker>

    <button type="button" wklyDateTimePickerDialog
      mode="datetime" [(value)]="value">Choose date and time</button>

    <input aria-label="Appointment date and time"
      wklyDateTimePickerOverlay mode="datetime" [(value)]="value">
  `,
})
export class PickerPresentationsComponent {
  value: WklyPickerValue = null;
}

When a transient selection commits

There are two useful exceptions to waiting for Confirm. In mode="date", choosing a calendar day automatically submits a valid selection. Now also validates and submits immediately. Manual entry otherwise waits for Confirm. Set [closeOnBackdrop]="false" if a backdrop click should leave the draft open, and inspect closed when your application needs the close reason.

Trigger inputs are readonly displays; editing happens inside the picker. The Material example adds a Material form field around that input, so it also needs Angular Material. Material does not provide the calendar. Transient pickers are created outside the trigger's DOM subtree, which also affects where their theme styles belong.

The optional CDK API reference documents the overlay directive and service.
