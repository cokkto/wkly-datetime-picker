Choose a calendar interpretation

A month is useful to read, but its shape depends on the calendar. WKLY gives navigation a steadier unit: a row of seven consecutive days. Each day has an integer coordinate, with 1970-01-01 as zero. A calendar adapter converts that coordinate to calendar fields and supplies month information, formatting, and date validation. Scrolling can keep the same week structure when those fields change.

Angular example: an explicit Gregorian adapter

Gregorian is the default. This example supplies it explicitly to show the public adapter input and its separate import. When supplying an adapter, choose its locale as well as the picker's locale. 

import { Component } from '@angular/core';
import { WklyGregorianCalendarAdapter } from '@wkly/adapters';
import { WklyDateTimePickerModule, WklyPickerValue } from '@wkly/datetime-picker';

@Component({
  selector: 'app-calendar-picker',
  standalone: true,
  imports: [WklyDateTimePickerModule],
  template: `
    <wkly-datetime-picker
      mode="date" locale="en-US"
      [calendarAdapter]="calendar" [(value)]="value">
    </wkly-datetime-picker>
  `,
})
export class CalendarPickerComponent {
  calendar = new WklyGregorianCalendarAdapter('en-US');
  value: WklyPickerValue = '2024-03-25T00:00:00.000Z';
}

Hebrew and civil Hijri source examples

The three demonstrations synchronize through the Gregorian UTC value, so their different date labels identify the same underlying day. The Hebrew example handles leap years with an extra month and uses @hebcal/core. The Hijri example uses tabular islamic-civil arithmetic and Intl formatting. It does not model observed lunar dates or the Umm al-Qura calendar.

Neither example adapter is bundled in npm. Their source is linked below; adapting it for an application requires its imports and dependencies too. Both support Gregorian 1900-01-01 through 2100-12-31, inclusive. The published Gregorian adapter supports years 0–9999. Adapter bounds apply to selection and navigation; changing the adapter does not extend its conversion range or perform timezone conversion.
