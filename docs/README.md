# WKLY project documentation

WKLY's npm outcome is one picker name, `@wkly/datetime-picker`, with a separate version line for each supported Angular major, 11–22. Consumers choose `@wkly/datetime-picker@N.x.x` for Angular `N`. The `N.S.A` version parts identify the Angular major, shared revision, and Angular-specific revision. Shared changes produce a new `N.S.0` artifact for every supported major; a fix confined to one Angular integration advances only that major's `A` version. See [package compatibility and release rules](COMPATIBILITY-CI.md).

Public values are canonical Gregorian UTC strings, while the displayed calendar can use another calendar adapter. The current source workspace has three Angular-independent projects (core week math, adapters and validation, shared presentation) and one Angular integration build target per major. The build targets retain separate internal package names. Isolated [publication builds](PUBLICATION.md) map them to the public name; the [development plan](DEVELOPMENT-PLAN.md) tracks automatic version updates. The shared runtime supplies the showcase and independently compiled versioned testbeds.
